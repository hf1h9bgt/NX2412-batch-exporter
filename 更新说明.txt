批量导出插件（便携版）更新说明
==================================

版本：20261031.01（Siemens NX2412 批量导出工具）
发行形式：便携式压缩包（解压即用，内置 Python 运行时，无需安装）

一、本版本新增/修复
1. 修复 DWG 批量导出“长时间不结束”和产生多余文件的问题：
   - 自动跳过没有视图的空白图纸页（如 NX 默认的 Sheet 1）；
   - 单张图纸输出 <文件名>.dwg；多张有内容的图纸按 NX 规则输出 <文件名>_<图纸名>.dwg；
   - 自动清理转换过程产生的 .log 中间文件。
2. 图纸导出支持 PDF + DWG 同时勾选：一次打开部件，按顺序完成两种格式导出。
3. 图纸导出页默认只添加文件名含 dwg 的图纸文件；模型导出页默认排除文件名含 dwg 的文件。
4. 界面优化：右侧控制区支持上下滚动；窗口加大并适配 Windows 高 DPI 缩放。
5. 新增免安装版：不需要先打开 NX，也不需要往 NX 里添加命令按钮。
6. 更新程序名与启动横幅，补充开源参考与 AI 修改说明。
7. 免安装版新增「使用 NX 后台转换引擎」勾选项（默认勾选）：
   - 勾选：程序启动即在后台预热一个 NX 转换引擎（首次约 10~20 秒，可正常使用界面），
     之后每次导出复用同一个后台 NX 进程，不再重复等待启动时间，导出更快；
     空闲约 30 分钟后后台 NX 自动退出释放内存，下次导出自动重启；
   - 取消勾选：每次导出临时启动 NX 后台进程（每次多等约 10~20 秒，不在后台常驻）；
   - 两种方式都不需要打开 NX。
8. 「所有打开文件 / 工作部件」按钮恢复为可点击：
   受 NX 接口限制，免安装版无法接管另一个已经打开的 NX 图形会话，因此点击按钮时
   会弹窗提示改用 NX 内插件（按 Alt+F8 运行 NX-batch-PDF-exporter.py）；
   在 NX 内插件中该功能完整可用（直连、无额外启动时间）。
9. 关闭免安装版窗口时会自动释放后台 NX 进程，不留残留进程。
10. 【本轮】免安装版改为「GitHub Releases 风格便携式压缩包」：
    - 解压后是一个「批量导出插件」文件夹，里面的程序文件逐个拆开（与 GitHub 仓库源码结构一致）：
      standalone.py / application.py / nxmodules.py / modelmodules.py / remote_*.py 等源码文件、
      图标、tcl/、lib/pypdf、locales/、doc/ 等资源；
    - 内置 Python 3.13 运行时（python\ 目录，含 tkinter），**不需要安装 Python**，
      也不需要安装本程序，解压即可用；
    - 双击文件夹中的「批量导出插件.exe」启动（70KB 启动器，作用等同快捷方式，带图标）；
      也可以双击「启动批量导出插件.vbs」或「启动批量导出插件.bat」；
    - 由于 Windows 快捷方式（.lnk）保存的是绝对路径，压缩包内预置的 .lnk 解压到其他路径
      会失效，因此没有把 .lnk 作为唯一入口；如需真正的 .lnk，双击「创建快捷方式.cmd」一次，
      会在当前文件夹生成「批量导出插件.lnk」，之后双击该 .lnk 即可（也可拖到桌面）；
    - 整个文件夹可复制到其他电脑直接使用（需已安装 NX2412 并具备可用许可）。
11. 【上一轮】「合并 PDF」功能优化：
    - 合并后的文件默认保存到被合并 PDF 所在路径（第一个 PDF 的文件夹）；
    - 合并文件默认名称为「组合1」（自动补 .pdf 后缀，可修改）；
    - 新增「保存路径」选项，可手动选择合并后 PDF 的保存文件夹；
    - 新增「保存时重命名」选项：勾选后点「开始合并」会先弹出另存为对话框，
      可修改最终路径和文件名；取消对话框则放弃本次合并；
    - 不勾选重命名时，若目标文件已存在会提示是否覆盖。

二、使用步骤
1. 把压缩包解压到任意位置（例如桌面），得到「批量导出插件」文件夹；
2. 双击文件夹内的「批量导出插件.exe」启动
   （本机需已安装 NX2412，不需要先打开它；第一次启动若较慢，是杀毒软件扫描新解压程序，稍等即可）；
3. 首次运行若提示找不到 NX2412，请选择 NX 安装目录（例如 D:\Program Files\Siemens\NX2412，
   该目录下应有 NXBIN 文件夹），选择后会记住；
4. 等待状态栏「转换引擎」显示“已就绪”（首次约 10~20 秒，期间可正常操作）；
5. 在“图纸导出 / 模型导出 / 合并 PDF”页签中添加文件、设置选项，点击开始；
6. 完成后可点右下角“打开输出文件夹”。

三、说明
- 便携版需要本机已安装 NX2412 且有可用许可（后台转换由 NX 完成）。
- 便携版始终使用独立的后台 NX 进程，不影响、也不会关闭你已经打开的 NX。
- 如需使用“已打开的 NX 会话”以及它的“已打开文件 / 工作部件”，请在 NX 内运行插件
  （Alt+F8 运行本文件夹中的 NX-batch-PDF-exporter.py）。
- DWG 转换较慢（单张图纸约 30~60 秒），STP 每件约 10~20 秒，请耐心等待。
- 本程序为绿色便携程序，不写注册表；运行后同目录会出现“批量导出插件.config.json”
  （仅记录 NX 安装目录）和可能的“批量导出插件.error.log”（异常日志）。
- 「python」文件夹是内置的 Python 运行时，请勿删除；「_internal」等不存在于便携版。
- 复制/移动文件夹后，如果 .lnk 快捷方式打不开，双击「创建快捷方式.cmd」重新生成一次即可，
  或直接双击「批量导出插件.exe」。
